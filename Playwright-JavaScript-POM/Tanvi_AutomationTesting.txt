Alerts, Dialogs & Modals:
-------------------------
JavaScript Alert :

Displays a message and an OK button . Playwright handles it using a dialog event.

Confirmation Dialog:

Asks the use to confirm or cancel an action, such as deleting some record


Prompt dialog:

Asks the user to enter text and click ok or cancel.


Modal popup:

An HTML component inside the web page , such as a login form , cookie notice or confirmation window,

JavaScript alerts , confirms and prompts are browser dialogs. HTML modals are webpage elements. They require different playwright techniques.

JavaScript alert:
-----------------
Suppose we click a button called show Alert . A browser dialog appears with the message 'Welcome to Playwright'. we want to playwright to read the message and click  OK Button.
